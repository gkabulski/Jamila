# Jamila Boughelaf Guglieri

Portfolio website for the artist Jamila Boughelaf Guglieri, live at **https://gkabulski.github.io/Jamila/**.

It's a plain Jekyll site that GitHub Pages builds automatically on every push to `main`.

## Where the content lives

| What | File |
|------|------|
| Artworks (title, medium, size, series, sold, featured on home) | `_data/artworks.yml` |
| Artwork images | `assets/images/artworks/` |
| Series filter buttons | `_data/series.yml` |
| Exhibitions | `_data/exhibitions.yml` |
| Materials strip on the home page | `_data/materials.yml` |
| Email, Instagram, representation | `_data/settings.yml` |
| Page text | `index.html`, `about/index.html`, `contact/index.html` |

To add an artwork, put the image in `assets/images/artworks/` and add an entry to `_data/artworks.yml`.
A visual editor (Pages CMS) will be added later on top of these same files.

## Design

Palette and textures are taken from Jamila's Sahara and henna paintings: sand, rust, henna green and gold leaf, with torn-paper edges. Fonts are Gloock and Instrument Sans, both self-hosted under the SIL Open Font License.
